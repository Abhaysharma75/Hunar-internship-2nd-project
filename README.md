# Hunar-internship-2nd-project
# 🌱 EchoGarden — Grow Through Every Feeling
# 🚀☯️LIVE DEPLOYMENT - https://abhaysharma75.github.io/Hunar-internship-2nd-project/
**Your Garden. Your Feelings. Your Space.**

EchoGarden is a creative, interactive emotional wellness web application designed to give users a calming digital space to express their feelings, reflect on their thoughts, and grow through everyday experiences.

Combining nature-inspired visuals, animated plants, mood-based experiences, and a supportive chat companion, EchoGarden transforms everyday thoughts into a personal digital garden.

## ✨ Key Features

- 🌿 **Mood-Based Garden:** Select a mood and discover a plant experience designed around your feelings.
- 🌸 **Animated Plant Experiences:** Enjoy gentle animations and nature-inspired visual interactions.
- 💬 **Little Leaf Chat Companion:** Interact with a rule-based chatbot that offers supportive responses and reflective questions.
- 📝 **Personal Thought Journal:** Write, save, review, and delete personal thoughts.
- 🌱 **Thought-to-Plant Interaction:** Certain keywords influence which plant grows from a thought.
- 🌙 **Dark Mode:** Switch between light and dark themes.
- 🔐 **Demo Login Interface:** A login-style entry screen with basic email and password-format validation.
- 📱 **Responsive Design:** A layout designed to work across desktop and mobile screens.
- 💾 **Browser Storage:** Save garden entries and theme preferences locally in the browser.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage and Session Storage
- CSS Animations
- Responsive Web Design

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Enter an email and a demo password containing at least six digits.
5. Explore the garden, interact with the mood buttons, plant thoughts, and try the chat companion.

No package installation is required for this front-end demo.

## 🎯 Project Goal

The goal of EchoGarden is to combine creative frontend development with an engaging, nature-inspired user experience. The project explores interactive UI design, DOM manipulation, event handling, browser storage, animations, and responsive layouts.

## ⚠️ Important Note

Little Leaf currently uses predefined, rule-based responses; it is not a real AI model. The login interface is a demonstration and does not provide secure authentication. Journal entries are stored in browser storage and should not be treated as a secure private diary.
